# Cs Club

Cs Club is a web application designed to provide resources and information for the Computer Science Club. This application allows users to explore courses, view details, and engage with club activities.

## Features

- Browse available courses
- View course details
- User-friendly interface
- Responsive design

## Technologies Used

- TypeScript
- React
- Vite
- Tailwind CSS

## Installation

To get started with the project, follow these steps:

1. Clone the repository:

    ```bash
    git clone https://github.com/Amr-Ma7moud/cs-club-hub.git
    ```

2. Navigate to the project directory:

    ```bash
    cd cs-club-hub
    ```

3. Install the dependencies:

    ```bash
    npm install
    ```

4. Start the development server:
    ```bash
    npm run dev
    ```
